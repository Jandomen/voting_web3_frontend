# Web3 Voting - Mini Blockchain

Este proyecto es una **simulación de votación descentralizada** utilizando una **mini blockchain propia**, desarrollada con **Node.js**, **GraphQL**, **React** y **Recharts** para mostrar resultados.  
Cada voto queda registrado como un bloque, garantizando **inmutabilidad y transparencia**.  

---

## **Características**

- Votaciones predefinidas con **opciones fijas**.  
- **IDs automáticos** para cada votación.  
- Cada voto se guarda como un **bloque en la blockchain**.  
- Visualización de resultados en **gráficas dinámicas** usando Recharts.  
- Simulación de **minado** simple para cada bloque.  
- Persistencia de la blockchain en un archivo JSON.  
- Configuración mediante **.env** en backend y frontend.  

---

## **Tecnologías**

- **Backend:** Node.js, Express, Apollo Server (GraphQL), dotenv, fs  
- **Frontend:** React, Apollo Client, Recharts, TailwindCSS  
- **Blockchain:** Mini blockchain propia en Node.js  
- **Persistencia:** Archivo JSON  
- **Variables de entorno:** `.env`
